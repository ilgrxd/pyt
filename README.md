# 🐍 PyAcademy — интерактивный курс Python

Образовательный сайт для изучения Python с нуля до профессионального уровня: теория, примеры, домашние задания с автопроверкой, подсказки, таймер и видео.

**Python выполняется прямо в браузере** (Pyodide), поэтому ученикам ничего не нужно устанавливать.

## Возможности

- **10 модулей, 27 уроков** — от `print("Привет")` до ООП, декораторов, генераторов и тестирования.
- **99 домашних заданий** с автоматической проверкой: сравнение вывода или скрытые тесты (`assert`).
- **Подсказки** — открываются по одной, чтобы не подглядывать всё сразу.
- **Таймер** на каждое задание и учёт лучшего времени.
- **Видеоуроки** по каждой теме: RuTube, VK Видео, Яндекс.Видео и YouTube.
- **Песочница** — свободный редактор кода прямо в браузере.
- **Аккаунты и синхронизация прогресса** между устройствами.
- **Рейтинг учеников** и **сертификат** с проверкой по коду.

## Быстрый старт

### Вариант 1. Просто открыть сайт (без аккаунтов)

Откройте `index.html` в браузере. Уроки и проверка заданий работают, прогресс сохраняется локально в браузере.

> Аккаунты, рейтинг и проверка сертификатов по коду требуют сервера — см. вариант 2.

### Вариант 2. Запустить сервер (аккаунты + синхронизация)

Нужен установленный **Python 3.8+** (проверить: `python --version`).

**Windows:** двойной клик по `start.cmd`

**Вручную (любая ОС):**

```bash
python server.py
```

Затем откройте http://localhost:3000

Сервер написан на чистой стандартной библиотеке Python — никакие пакеты устанавливать не нужно.

## Как добавить свой материал

### Изменить урок

Откройте `data/curriculum.js` и найдите нужный урок. Структура урока:

```js
{
  id: "m1l1",
  title: "Что такое Python и первая программа",
  duration: 12,
  video: { title: "Знакомство с Python", query: "Python с нуля урок 1" },
  theory: `<p>Текст теории в HTML...</p>`,
  examples: [
    { title: "Привет, мир!", code: `print("Привет, мир!")` }
  ],
  homework: [
    {
      id: "m1l1h1",
      title: "Первое приветствие",
      task: `Напишите программу, которая выводит <code>Привет, мир!</code>`,
      starter: `# ваш код\n`,
      check: { type: "output", expected: "Привет, мир!" },
      hints: ["Используйте print()", "Текст в кавычках"],
      solution: `print("Привет, мир!")`
    }
  ]
}
```

Два типа проверки заданий:

- `check: { type: "output", expected: "ожидаемый вывод" }` — сверяет вывод программы;
- `check: { type: "tests", tests: "assert ..." }` — выполняет скрытые тесты Python.

### Добавить своё видео

В уроке укажите конкретный ролик YouTube:

```js
video: { title: "Название", youtubeId: "dQw4w9WgXcQ" }
```

где `youtubeId` — часть ссылки после `watch?v=`.

Если ролик не задан, сайт покажет кнопки поиска по теме на разных платформах.

### Добавить задание

Допишите объект в массив `homework` нужного урока или в `data/extra.js`.

> После правок проверьте, что эталонное решение проходит собственные тесты.

## Развёртывание в интернете

### Render.com (бесплатно, ссылка для всех)

1. Загрузите проект на GitHub (см. ниже).
2. Зарегистрируйтесь на [render.com](https://render.com) → **New** → **Web Service**.
3. Подключите репозиторий.
4. Настройки:
   - **Runtime:** Python
   - **Build Command:** оставить пустым
   - **Start Command:** `python server.py`
5. Через минуту получите ссылку вида `https://имя.onrender.com`.

В репозитории есть готовый файл `render.yaml` — Render применит настройки автоматически (BluePrint).

**Важно про бесплатный тариф:**

- Сервис «засыпает» после ~15 минут простоя; первый заход после сна — около 30 секунд.
- Файловая система эфемерна: при перезапуске данные аккаунтов могут обнулиться. Для сохранности подключите постоянный диск (платно) и задайте переменную окружения `DATA_DIR` — путь к диску (например `/var/data`).

### Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `3000` | Порт сервера |
| `HOST` | `0.0.0.0` | Адрес прослушивания |
| `DATA_DIR` | `./server-data` | Каталог для `users.json` и `sessions.json` |

## Безопасность

- Пароли хранятся в виде хэша (PBKDF2-SHA256, 100 000 итераций), не в открытом виде.
- Доступ к `server.py`, `start.cmd` и каталогу данных через сайт запрещён.
- `server-data/users.json` содержит данные пользователей — не выкладывайте его в открытый доступ и делайте резервные копии.

## Частые вопросы

**Первый запуск Python долгий.** При первом открытии страницы браузер скачивает интерпретатор Pyodide (~10–20 секунд). Нужен интернет. Дальше всё мгновенно.

**Видео не открывается.** YouTube в России доступен только через VPN. Используйте кнопки RuTube, VK Видео или Яндекс.Видео — они работают без VPN.

**Ссылка `localhost:3000` не открывается у друзей.** `localhost` — это ваш компьютер. Чтобы сайт был доступен другим, см. раздел «Развёртывание в интернете» или используйте адрес вашего компьютера в локальной сети (команда `ipconfig`).
